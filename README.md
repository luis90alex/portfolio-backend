# Portfolio Backend

Portfolio personal enfocado a desarrollo backend, construido a partir de un template base y adaptado con contenido, estructura y mejoras propias.

## 🚀 Sobre el proyecto

Este portfolio muestra mi experiencia en desarrollo backend con Java, Spring Boot, Kafka y sistemas distribuidos, junto con proyectos representativos.

## 🛠️ Personalización realizada

* Adaptación completa del contenido (experiencia, proyectos, tecnologías)
* Reestructuración del enfoque hacia backend
* Mejora de descripciones técnicas
* Integración de nuevos proyectos y secciones

## 📄 Créditos

Este proyecto está basado en un template creado por MoureDev.
Repositorio original: https://github.com/mouredev/portafolio-template
